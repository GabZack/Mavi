# Mavi

**Project under development**

Mavi is a program that listens to what the user says, asks to groq and answers it in the terminal. Everything the user says is sent to Google and the question go to the groq, so an internet connection is required for the program to work. To use these features, run `Perguntar.py`. To install all the dependencies, run `pip install -r requirements.txt`. The Python version used is 3.13. It's necessary to has a groq api key, thats in the .env

## Planned

The main goal is to become a virtual assistant that uses a wake word system, with commands, and speak the answer out loud
