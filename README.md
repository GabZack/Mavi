# Mavi

**Project under development**

Mavi is a program that listens to what the user says and shows it in the terminal. Everything the user says is sent to Google, so an internet connection is required for the program to work. To use these features, run `Ouvir.py`. To install all the dependencies, run `pip install -r requirements.txt`. The Python version used is 3.13.

## Planned

The main goal is to become a virtual assistant that uses Groq to get real-time answers about what was said, together with a wake word system.
